# Mushak 0.0.6

This release includes MX Master family and MX Vertical support, dynamic device
settings, and the disconnected-device fix from the local MX family test build.
The added model and connection paths remain experimental while physical testing
across those devices is pending.

## Changes

- Discover the original MX Master, 2S, 3, 3S, 4, their Mac and business variants,
  and MX Vertical through reported HID++ mouse capabilities.
- Try Bluetooth, Unifying, Bolt, other compatible receivers, and wired USB where
  supported. Skip receiver keyboards and empty slots.
- Show the mouse's reported name and only its supported settings. Select DPI
  from the values reported by the mouse, with no generic range fallback.
- Add battery, SmartShift, DPI, and reprogrammable-button protocol variants.
  Extra button mappings follow application profiles and return to native
  behavior when Mushak pauses or exits.
- Remember the last mouse name across disconnections and app restarts, with
  disconnected status. Show "No device" before the first mouse connects.
- Exclude built-in I2C touchpads and empty receivers from connected-mouse status.
- Add `--diagnose-device` for read-only device and capability reports.

## Install and update

Use the MSI installer or portable executable below. Scoop and WinGet updates use
the same portable executable after their manifests update. Microsoft Store uses
package version 1.0.6.0 and becomes available after submission and certification.

The GitHub executable and MSI are unsigned. Microsoft signs the Store package
after certification. The unsigned MSIX below is the Partner Center upload, not
a standalone installer. Check downloads against `SHA256SUMS.txt`.

Existing configuration remains readable. The last-device name is stored
separately and never restores stale battery, DPI, or connection state.

## Validation and limits

The MX family implementation has protocol fixtures for the supported families
and regression coverage for device presence and remembered identity. All 41
tests, the Windows release build, the MSI startup registration check, and MSIX
pack/unpack identity validation passed for 0.0.6. Live MX Master 2S Bluetooth
discovery passed again on the release executable. Local Windows App
Certification Kit testing requires an elevated session and has not run.
Physical behavior and the other model and
connection combinations still need testing. See the
[validation record](https://github.com/divyangchauhan/Mushak/blob/v0.0.6/docs/mx-family-support.md).

Mushak manages one active HID++ mouse at a time. It does not add Flow, Actions
Ring, hardware gesture feature 0x6501, or haptic intensity controls.
