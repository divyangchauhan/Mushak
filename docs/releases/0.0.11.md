# Mushak 0.0.11

The button editor now keeps the Actions and Keyboard shortcut tabs in place while you edit. The mouse diagram stays still when you switch tabs. Smaller windows use a searchable list of the buttons your mouse reports.

- Use the redesigned Buttons, Scroll, Gestures, Profiles, and Device screens in light or dark mode.
- Browse actions by category, record a keyboard shortcut, or cancel a draft. Existing profiles and saved mappings carry over.

## Also included for Scoop and WinGet users updating from 0.0.8

- Customize tap and swipe gestures per application, or inherit the default profile.
- Assign wheel-mode switching or two pointer speeds to supported wheel-mode buttons. The speed editor lists the DPI values reported by your mouse.
- Accidental wheel scrolling is suppressed while middle click is held and for 150 milliseconds after release. Pausing Mushak disables the filter.

The Windows x64 release includes a portable executable, ZIP, MSI installer, and the Microsoft Store package. The Store package version is 1.0.11.0.
