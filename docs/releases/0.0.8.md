# Mushak 0.0.8

The Buttons page now shows an MX Master mouse diagram. Click a button marker
or its label to choose a preset or custom shortcut in a configuration popover.

## Changes

- Add diagrams for the original MX Master, 2S, 3, 3S, and 4, including Mac and
  Business variants. The original and 2S share one body diagram; the 3 and 3S
  share another. The 4 has separate gesture and Haptic Sense Panel markers.
- Show only controls reported by the connected mouse. Keep additional reported
  controls available below the diagram and retain the list for other mice and
  narrow windows.
- Preserve per-application button mappings, global gesture actions, and offline
  editing of saved Back, Forward, and Middle mappings for remembered devices.
- Keep action popovers within the window, add a close button, reset search on
  opening, and restore focus to the selected marker on dismissal.
- Include the static Windows runtime fix previously submitted to the Store as
  0.0.7. Distributed executables no longer require the VC redistributable.

## Install and update

Use the MSI installer or portable executable. The MSI registers per-user startup
with Windows. Existing configuration remains readable. Scoop and WinGet use
the portable executable after their manifests update.

The Microsoft Store package version is 1.0.8.0. Store availability depends on
submission and Microsoft certification. The unsigned MSIX is the Partner Center
upload, not a standalone installer. Microsoft signs the certified Store package.
The GitHub executable and MSI are unsigned. Check downloads against SHA256SUMS.txt.

## Validation and limits

All 46 unit tests pass. GPU-rendered interaction checks passed for all five
Master generations, Mac and Business names, both themes, mapping persistence,
profile isolation, custom shortcuts, extra controls, disconnected editing,
window sizes, and scrolling. Cross-model UI checks use fixture device status.
Physical button behavior and reconnection across other models and connections
remain manual checks.

This release does not add Flow, Actions Ring, haptic intensity controls, or
simultaneous management of multiple mice. Logitech product artwork is separate
from Mushak's MIT license; see assets/devices/README.md for provenance.
