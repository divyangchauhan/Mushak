# Mushak 0.0.10

Middle clicks now suppress accidental wheel scrolling while the wheel is pressed
and for 150 milliseconds after release. This also briefly blocks intentional
scrolling immediately after a middle click. Pausing Mushak disables the filter.

High-resolution wheel movement during that guard is discarded, including pending
movement and fractional scroll units, so it cannot accumulate into a later jump.
Existing settings remain compatible.

## Also included since GitHub 0.0.8

These changes shipped in Store version 0.0.9 and are new to GitHub users:

- Button assignments show selection feedback and close after 120 milliseconds.
- Supported wheel-mode buttons can switch ratchet/free-spin or two pointer speeds.
- A separate editor offers the mouse's supported DPI values.
- Saved extra-button and gesture mappings can be edited while disconnected.
- Per-app gesture assignments inherit defaults until customized and can reset
  to those defaults.

## Validation and limits

All 58 automated tests pass, including the single-instance check. The user tested the installed scrolling fix and accepted the result after the
release guard was added. Automated tests cover held clicks, release jitter, and
scrolling resuming at the end of the guard. This is not physical validation on
every mouse model. Wheel movement arriving before the button press registers
remains outside the guard.
