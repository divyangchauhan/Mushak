# Mushak 0.0.9

Button assignments now show a brief selection animation and close after 120 ms.
Wheel-mode actions use the same clickable rows as other assignments.

## Changes

- Choose ratchet/free-spin switching or two pointer speeds from the wheel-mode
  button picker when the connected mouse reports support.
- Configure the two DPI values in a separate editor using supported values.
- Edit saved extra-button and gesture mappings while disconnected. Hardware
  actions remain visible with a reconnect message when unavailable.
- Choose a supported gesture trigger and customize gesture actions per app.
  Profiles inherit default gestures until customized and can reset to defaults.
- Show selection feedback for preset actions, native behavior, disabled buttons,
  custom shortcuts, and pointer-speed assignments.

## Store package

App version 0.0.9 maps to Microsoft Store package 1.0.9.0. Existing saved
configuration remains compatible. Store availability requires certification.

## Validation and limits

All 57 automated tests pass. The user accepted the installed picker behavior
and shorter animation. Physical testing across all mouse models remains pending.
Controls depend on the mouse's reported capabilities.
